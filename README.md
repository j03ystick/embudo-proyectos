# Embudo de Proyectos

Página web que muestra el estatus de los proyectos de la compañía en forma de embudo.

- `index.html`: la página (estructura y lógica para dibujar el embudo).
- `styles.css`: colores, tamaños y forma del embudo.
- `projects.json`: los datos (etapas y proyectos). **Este es el único archivo que hay que editar para actualizar la información.**
